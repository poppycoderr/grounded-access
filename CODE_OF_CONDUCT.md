# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work rather than the person, and don't harass anyone in any project space.

Report unacceptable behaviour privately to the maintainer through the contact on the [maintainer's GitHub profile](https://github.com/poppycoderr). Reports are handled confidentially.

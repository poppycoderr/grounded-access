# Project Borealis: Metering Event Schema

This fictional document is confidential and is for members of Project Borealis only.

## Fields

A metering event has an event identifier, a customer account, a unit, a quantity and the time at which the usage happened.

## Identifiers

Event identifiers are generated by the producer. The pricing engine drops an event whose identifier it has already seen in the last 40 days.

## Versions

The schema carries a version number. Producers may send the current and the previous version.

# Performance Budgets

This fictional standard is part of the Northstar Cloud engineering handbook.

## Web pages

Every page of the web application loads its main content within 2.5 seconds on a mid-range laptop over a typical home connection.

## Checking

The build measures the size of the web application's scripts and fails if they grow by more than 5 percent in one change.

## Exceptions

An exception is granted by the frontend lead for one release at a time.

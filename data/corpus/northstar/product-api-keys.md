# API Keys

This fictional page is part of the public Northstar Cloud product documentation.

## Creating keys

Administrators create API keys in the console. A key is shown once, when it is created.

## Scopes

Each key has scopes that limit what it can do, for example read-only access to invoices.

## Expiry

Keys can be given an expiry date. Keys that have not been used for 180 days are disabled automatically.

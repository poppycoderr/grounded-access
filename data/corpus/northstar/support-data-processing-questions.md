# Questions about Data Processing

This fictional page describes how Northstar Cloud works.

## Data location

Customer data is stored in the region the customer selected when the account was created. It can be moved to another region on request.

## Subprocessors

The list of subprocessors is published in the trust center, and customers can subscribe to be told about changes 30 days in advance.

## Agreements

The data processing agreement is part of the terms of service and does not need to be signed separately.

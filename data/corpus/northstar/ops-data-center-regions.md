# Regions

This fictional page describes how Northstar Cloud works.

## Regions

Northstar Cloud runs in four regions: eu-central, eu-west, us-east and us-west.

## Customer data

A customer's data stays in the region chosen when the account was created; backups stay in a second region on the same continent.

## New regions

A new region is opened only after a security review and a full disaster recovery exercise in that region.

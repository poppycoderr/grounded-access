# Bug Bounty Program

This fictional page is public and explains Northstar Cloud practices to customers.

## Scope

The bug bounty program covers the web application, the public API and the mobile apps. Testing that harms other customers is not allowed.

## Rewards

Rewards depend on severity and range from 100 EUR for a low-severity issue to 10,000 EUR for a critical one.

## Response

The security team acknowledges every report within three business days.

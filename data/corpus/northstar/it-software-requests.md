# Requesting Software

This fictional guide describes how things work at Northstar Cloud.

## Software catalogue

Software from the catalogue in the IT portal can be installed by anyone without approval.

## New software

Software that is not in the catalogue is requested in the IT portal. The security team reviews the request within five working days.

## Browser extensions

Browser extensions follow the same rules as other software. Extensions that can read every website are approved only for a documented business need.

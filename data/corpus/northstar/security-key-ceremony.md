# Root Key Ceremony

This fictional procedure is restricted to named key custodians.

## Custodians

The root encryption key is split into five shares. Any three custodians together can reconstruct it.

## Storage

Each share is kept in a tamper-evident envelope in a different bank deposit box. The locations are never written down in the same place.

## Schedule

The ceremony is repeated every two years, or immediately after a custodian leaves the company.
